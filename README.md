  * Project title & description
"ግጥም-ሲጥም" is a fully responsive, Amharic-language poetry website built with vanilla HTML, CSS, and JavaScript. 
The platform allows poets to share their work, discover new poems, and connect with the poetry community.
 
  *Features: 
     1. Multi-Page Website Structure:
Home(ቤት-ለእንግዳ) Page - Hero section, book recommendations, and poem of the week.
Poems(መሶብ) Page - Collection of poems with filtering and interaction features.
Contact(ጓዳ) Page - Form for submitting original poems.
About(ስለ-እኛ) Page - Information about the platform and team.
     2. Interactive Features:
Poem Submission System - Users can submit poems via contact form.
Poem Filtering - Filter between "all Poems" and "User Submitted" poems.
Like/Save Functionality - Interactive buttons with visual feedback.
Read More/Read Less - Expandable poem content with toggle buttons.
LocalStorage Integration - Persists submitted poems and user preferences.
 
  * Technologies used:
HTML5 - Semantic markup structure
CSS - Custom styling.
JavaScript - Client-side functionality
LocalStorage API - Data persistence

  * How to run the project:
Download all project files
Open home.html in any modern web browser
No build tools or servers required
Works offline after initial load
